# Lariscus

Local-first, open-source software for work that people and AI agents share. Your data stays in plain files you own, agents do the legwork, and you stay in charge of what actually changes.

## Projects

| | |
|---|---|
| **[Drey](https://github.com/lariscus/Drey)** | A private Markdown note vault with live preview, daily notes, tasks, tags, search and an optional AI assistant that works on your notes through permissioned tools. Windows and Linux. · [Website](https://lariscus.de/drey/) |
| **[dricket](https://github.com/lariscus/dricket)** | Tickets that live in Git. Claimed by fast-forward push, no server, safe for humans and agents. One static binary. · [Website](https://lariscus.de/dricket/) |

## Principles

- **Local-first:** plain Markdown, plain Git, no lock-in.
- **Agent-ready:** MCP, a strict CLI and explicit exit codes.
- **You decide:** writes ask first unless you say otherwise; anything that leaves your machine is opt-in.
